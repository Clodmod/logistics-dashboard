# 智慧物流数据大屏

基于 HTML + ECharts 实现的智慧物流数据可视化大屏，适配 1920×1080 分辨率，支持等比缩放。

## 📺 功能模块

- **货量统计** — 货量趋势折线图 + 容量/存量/利用率 KPI
- **人货场统计** — 人员、拣货、车辆、设备 2×2 指标卡片
- **订单详情** — 实时滚动订单列表
- **监控画面** — 三路监控视频模拟画面
- **出入库数据统计** — 入库/出库趋势柱状图 + KPI
- **设备统计** — 设备状态饼图 + 正常/待机/离线/故障计数
- **温湿度** — 温度、湿度双仪表盘
- **告警信息** — 分级告警列表（高/中/低）

## 🚀 快速开始

直接用浏览器打开 `index.html` 即可。

或者部署到任意静态服务器：

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```

## 📐 技术栈

- HTML5 + CSS3
- ECharts 5.x
- 纯前端模拟数据，无后端依赖

## 📝 说明

- 数据为前端模拟，可对接真实 API
- 设计分辨率 1920×1080，自动等比缩放适配不同屏幕
